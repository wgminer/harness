Harness

A Mac app I made for myself.

I wanted somewhere to talk ideas through that wasn't a browser tab. It does dictation, a plain chat with no persona, notes, and tasks, and it all stays on my Mac. I use it every day, so I keep tinkering with it.

Download for macOS

Free and open source. For Apple silicon Macs on macOS 12 or later. Source on GitHub

Talk instead of type

Press Fn from any app and say what you're thinking. Apple Speech transcribes it on the Mac, it lands in a conversation, and the reply streams back.

Grill mode

Switch a conversation to Grill and it interviews you instead of answering. One question at a time, with the choices in the composer. Useful when the hard part is knowing what you think.

Notes for the long version

Chat stays short. Longer writing goes into a Markdown note that the model can draft into or suggest edits to, and that I can keep editing by hand.

Tasks you can say out loud

Ask in chat or dictate, and tasks land in a plain list with tags. Nothing to set up and no project hierarchy.

Why I built it

Commercial tools optimize for a mainstream audience and lock-in. This one is personal, and makes three promises:

Data I can leave with
Conversations, notes, and tasks live on my Mac. Sync to the phone is optional.
Context I can inspect
Each reply can show exactly what went to the model: prompt, memories, and messages.
Voice when typing is wrong
Press Fn anywhere to dictate. Speech is transcribed on the Mac by Apple Speech.

Needs macOS 12 Monterey or later on Apple silicon, microphone access for dictation, and an OpenAI API key or a local model through Ollama. Built with Tauri, Rust, React, and Swift.
